Análise Exploratória de Dados Climáticos

Temperaturas extremas da cidade de Sarapuí, São Paulo a partir de dados do INMET

Sobre o Projeto

A proposta deste projeto é observar um efeito bem conhecido pela ciência, que já é de senso comum e empírico: o aumento da temperatura média global.

Aqui vamos explorar as temperaturas extremas, mínimas e máximas dos anos de 2010, 2014, 2020 e 2024 da cidade de Sarapuí, São Paulo e entender melhor como o projeto pode ser aprimorado no futuro.

Para que este projeto pudesse ser realizado foi-se utilizado dados abertos do inmet.gov, coletando dados de estação metereológica, além da ferramenta Google Sheets e das tecnologias Pandas, Github Pages, Javascript, D3.js, HTML e CSS.

Metodologia

Consistiu na coleta de dados públicos do inmet.gov entre os anos de 2010, 2014, 2020 e 2024 no formato csv. É possível observar com a tabela abaixo de Dados Climáticos 2024 como o INMET organiza os dados exportados em csv.

Para a publicação deste projeto, apenas a coluna hora, data e temperatura foram utilizadas.

No tratamento de dados alguns procedimentos precisaram ser realizados, a hora, por exemplo, é informada em UTC, então uma coluna calculada foi criada para a conversão da hora em BRT timezone.

com decremento de 3 horas para que a hora atualizada fosse referente ao horário de Brasília consequentemente uma nova coluna calculada precisou ser criada já que meia-noite UTC corresponde a 9 da noite BRT então neste caso estaríamos falando do dia anterior de acordo com o horário de Brasília então duas colunas calculadas foram adicionadas para corresponder ao fuso horário de Brasília mas as colunas com fuso horário UTC foram mantidas para fins de consulta caso fossem necessárias
