Análise Exploratória de Dados Climáticos

Temperaturas extremas da cidade de Sarapuí, São Paulo a partir da estação metereológica de São Miguel Arcanjo, SP, fornecido pelo INMET.

Sobre o Projeto

Aqui vamos explorar as temperaturas extremas dos anos de 2010, 2014, 2020 e 2024 da cidade de Sarapuí, SP e entender melhor como a base de dados utilizada pode oferecer insights para aprimorações futuras do projeto.

Utilizou-se dados abertos do inmet.gov, além da ferramenta Google Sheets e das tecnologias Pandas, Github Pages, Javascript, Charts.js, HTML e CSS.

Metodologia

A metodologia escolhida foi uma análise exploratória utilizando Pandas e Python para destacar as temperaturas extremas dos anos selecionados.

Foram trabalhados data, hora e temperatura na visualização dos gráficos.

Coleta de Dados

Foram coletados dados públicos oferecidos pelo inmet.gov exportados em csv. É possível observar a tabela original oferecida pelo INMET na seção de Dados Climáticos 2024.

Processamento

O processo de ETL foi feito no Google Sheets. Linhas adicionais foram removidas e duas colunas calculadas foram adicionadas: a primeira foi para adicionar o fuso horário local (BRT), já queo INMET trabalha com UTC; a segunda coluna foram datas correspondentes a cada horário, já que 00:00 UTC equivale a 21:00 BRT do dia anterior.

Visualização

A visualização foi realizada em Charts.js para ser exibida nesta página, ilustrando máximas e mínimas de cada ano trabalhado, exibindo data, horário e a temperatura.

💡 Conclusões

A base de dados oferecida pelo INMET é muito rica e oferece muitas possibilidades de manipulação. Segue abaixo algumas perguntas possíveis de serem respondidas com a base do INMET.

  • Quantos dias, em um determinado ano, as temperaturas ficaram acima de 30ºC?
  • Quantos dias, em uma determinada estação do ano, choveu?
  • Qual dia choveu mais ou menos?
  • Quantos dias ficou sem chover?
  • Existe relação em dias que choveram mais e temperaturas mais altas ou baixas?
  • A prevalencia de altas e baixas temperaturas ao longo do ano tem aumentado, diminuido ou se mantido?
  • Combinar dados oferecidos pelo INMET e calcular sensação térmica.
  • Criar coluna calculada para separar os meses do ano por estações.
  • Associar temperaturas extremas a fenômenos climáticos, complementando com novas bases de dados.
  • Associar outras estações metereológicas para corrigir dados inconsistentes e faltantes.
